## Project Overview

This project investigates seasonal river ice dynamics
using Sentinel-1 SAR imagery.

### Research Question

How do radar backscatter patterns change through
freeze-up and breakup?

### Methods

- Sentinel-1 acquisition
- Preprocessing
- Ice masking
- Time series analysis
